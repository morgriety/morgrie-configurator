# Source snapshot correspondence

The maintained application, device definitions and build scripts have one source: the development repository. This public tree is generated by scripts/export-public-source.cjs using resources/public-source-policy.json. It is not a separately maintained application fork.

SOURCE_SNAPSHOT.json gives the exact development HEAD, whether local changes were present, sourceDateEpoch and frozen lock hash. SOURCE-FILES.json maps source paths to export paths and hashes. Clean Git does not itself constitute RC approval. WORKTREE_PREPARATION_NOT_FROZEN_RC means this is explicitly not final release corresponding source.

All included application, definition and build files are byte-preserved. Differences are limited to documented public documentation mappings, generated provenance, omission of proprietary Gotham binaries, internal documents/caches/Git history/deployment workflows, a legacy unused download helper and two unused React template SVGs. The committed MORGRIE gradient favicon and HTML cache reference come from the same development source and are not replaced by old VIA assets.

Both public and licensed artifacts are built from this same code. Mode selection only controls checked font resources and public fallback transformation, plus license notices. Licensed binaries must stay outside public source publishing. See BUILDING.md for regeneration, source publication and validation requirements.

VALIDATION.md explains the generated identity of each export and separately records dated software validation history. Exporting does not grant new test acceptance. No device writes, Git publication or deployment are performed by source export.
